# Agent GhostReaper

LLM 多 Agent 驱动的自主渗透测试系统，仅供授权测试使用。单二进制，内嵌 Web 面板。

## 系统介绍

你提供目标资产、测试目标和操作限制，主宰拆分工作，虫群单位在同一会话里执行、验证、自查并提交漏洞；系统核验证据和交卷条件，通过后保存漏洞与复现材料。你可以在面板查看进展、与牧者对话、调整任务和处理审批，最后从账本导出报告。整个任务可由多个单位并行推进，普通观察记为事实，未通过核验的漏洞按补考结果记录为证据不足。

**命名体系**（面板常用词）

| 名称 | 含义 |
|------|------|
| 主宰 | 根据目标和已有结果安排工作、调整方向 |
| 牧者 | 任务对话入口，用于查询进展、追问和下达调整要求 |
| 虫群单位 | 领取具体工作的执行者，通常在同一会话完成探索、证明、自查和交卷 |
| 意图 | 一项具体工作，说明做什么、针对什么对象、预期看到什么 |
| 事实 / 漏洞 | 事实记录实际观察；漏洞条目保存问题、证据和核验结果，未通过者标明证据不足 |
| 全景图 / 资产网 | 全景图展示来源与产出关系；资产网展示目标资产及关联 |
| 年轮 / 镜 | 年轮保存事件账本；镜记录请求与响应，供证据回查 |
| RoE | 授权面板，管理资产范围、操作约束和审批 |

## 使用方法

### 产物

| 产物 | 用在 |
|------|------|
| ghostreaper-darwin-arm64 | Mac（Apple 芯片） |
| ghostreaper-darwin-amd64 | Mac（Intel 芯片） |
| ghostreaper-linux-amd64 | Linux（x86-64） |
| ghostreaper-windows-amd64.exe | Windows（x86-64） |

### 运行

建议单独建一个文件夹，并从该目录启动。默认数据保存在启动时的工作目录，不一定是程序所在目录。

**Mac / Linux**

    chmod +x ghostreaper-darwin-arm64    # 文件名按实际平台
    ./ghostreaper-darwin-arm64

Mac 若提示无法打开：右键文件 → 打开，放行一次。

**Windows**

双击 exe，或在 cmd 中运行。执行外部命令需要在 PATH 中能找到 bash；系统不预装攻击工具。

**通用**

启动后浏览器打开 http://127.0.0.1:28282，首次访问设置面板登录密码。在“LLM配置”中新增模型并激活主用，再创建任务。

以下三项应一并备份；备份前先停止程序，丢失密钥后加密配置无法解密：

| 文件 | 是什么 |
|------|--------|
| ghostreaper.db | 账本（任务 / 发现 / 流量记录及配置） |
| ghostreaper.db.key | 加密主密钥 |
| tasks/ | 会话、证据原文和任务工作目录 |

**运行后的目录结构**

    ghostreaper-darwin-arm64      程序本体（以 Mac 为例）
    ghostreaper.db                账本
    ghostreaper.db-shm            账本伴生文件（运行时自动出现）
    ghostreaper.db-wal            同上
    ghostreaper.db.key            加密密钥
    logs/                         运行日志
    tasks/
    ├── t-a1b2c3d4/               每个任务一个目录
    │   ├── transcripts/          会话记录
    │   └── is1/ is2/ …           各意图工作目录
    ├── blobs/                    原始数据存储（流量原文等）
    ├── mirror-ca-bundle.pem      HTTPS 留痕使用的信任包
    └── skills/humanizer/         内置文风技能

### 更新版本

升级到 v1.3.0：先导出旧任务报告并备份数据，再停止程序、换上新版。打开新版后删除旧任务，勾选“同时删除相关数据和账本”，然后重新建任务。旧任务格式不兼容，不能接着用。

一般重启后，原来在跑的任务会在模型可用时重新排队或运行；冬眠任务仍需手动唤醒。

## 版本更新记录

### v1.3.0（2026-11-23）

- **升级要重建任务**：升级前导出旧报告、备份数据。升级后删除旧任务，勾选“同时删除相关数据和账本”，再建新任务；旧任务不能接着用。
- **一个单位把漏洞做完**：通常由同一个虫群单位完成测试、验证、自查和提交，系统再核验证据。没通过可补做一次，仍不过就记“证据不足”；不再固定另派单位反证。
- **等待不占着名额**：等审批、范围确认、模型或人工继续超过五分钟，先把名额让给其他工作，条件满足后沿原会话续跑。唤醒任务后可立即领取已有工作。
- **虫群能查已有结果**：领取工作时能看到任务概况，也能查询已有资产、事实、漏洞和意图，仍按任务授权执行。
- **发现与会话重新分组**：发现页分意图、事实、漏洞三栏，详情可以追问，新内容有未读提醒；会话分执行中、等待、排队中、已完成，工作台显示执行、排队和等待数量。
- **图按实际记录展示**：全景图、资产网和漏洞详情图共用账本数据，资产树按地址分层，工作台也使用当前图数据。旧图和独立假设机制已删除。
- **对话框补齐小功能**：增加中文组词时的回车保护、思考内容展示和“继续”入口。思考默认开启，手动关闭过的保持关闭。
- **清理旧代码**：删除无用代码和依赖；虫群、描述提取和资产整理的输出长度按模型配置走。
- **还没解决的限制**：原生中文输入法尚未完成实测；节点特别多时仍会掉帧、线条重叠；曾出现一次思考内容停止输出，后续复测通过，但原因还没查明。

### v1.2.3（2026-11-13）

- RoE 授权范围机制重构：查资料的外部网站自动识别放行，不再连环弹审批；范围外目标弹卡直问"要不要纳入测试范围"，批准后原会话接着干；摘除目标时相关工作立即收场、不留残留。
- 范围卡只答一个问题：资产卡两键（加入资产／禁止测试）；对信息源的攻击行为才需批准，同一单位问一次不重复打扰。
- 目标识别改用模型判断：命令里的参数数字（如扫描速率）不再被误当成目标拦截；没见过的命令写法也能正确识别要连的目标，不再漏拦。
- 每条审批记录都可反悔：取消加入、恢复纳入、撤销攻击许可等，点开记录即可反向操作。
- 确认的漏洞必有复现数据包：确认依据的请求自动进复现包，任何环节出问题也不会出现"漏洞确认了却没有数据包"。
- 审批卡按命令实际内容说明：纯查看命令不再顶着"修改"的名头；同步骤自动放行的记录折叠成一行，不再刷屏。

### v1.2.2（2026-11-10）

- 审批记录不再报错：点开任何一条审批记录都能正常看详情（此前无裁决人的记录会整页报错）。
- 界面局部出错不再白屏：页面渲染出错只降级为该区块的错误提示，其余区域照常可用，刷新即恢复。
- 发现页排序更顺手：成果新的在最上面；假设、事实、锤炼三页正在动的置顶、废弃的沉底。
- 复现数据包只给能用的：失败的请求和与漏洞无关的请求不再混进复现步骤；挑不出可用的包会直接说明原因，不再硬塞没有价值的请求。
- 目标证书有问题也能留痕：自签、过期证书的站点照常抓包（此前会连接失败、复现缺原料）；不走代理直连的命令也能从执行记录还原出可复制的请求包。
- 拦截不再误杀干活单位：探测地址里的词、代码字符串里的词不再被当成破坏命令；拦截只拒绝那一条命令，单位换个方法继续干，同一规则连撞 3 次才停。
- 验证过程实时说人话：锤炼中的声明不用等出结果，每轮反证就是"疑点、怎么验的、结论"三段人话；事实、假设的文字同样按报告标准写。
- 节点详情不再倒机器字段：步骤、事实、假设的详情按人话字段呈现，机器数据折叠在"原始数据"里可查。
- 界面文字全面按报告标准统一：研判叙述、意图标题、虫群总结、牧者回答、各类提示文案都升级到与成果报告同级的可读性。

### v1.2.1（2026-11-09）

- 修复范围误判：给域名测域名时，浏览器版本号、请求头和测试参数里的网址不再被当成越界目标误拦。
- 范围审批改版：要测授权外的目标时先拦下等你批准，批准后原会话接着干；红队任务直接测、可随时叫停。
- 审批界面统一：所有审批卡一个样子，批准时可以附一句要求带给虫群；审批记录能翻到底，点开看全部详情。
- 建任务更直观：填资产时实时显示能测多大范围，描述里"只测某某"会自动填到对应位置。
- 牧者全权：在对话里就能改目标、资产、注意事项、优先级，停掉其他方向只做一件事，或冬眠、终止任务。
- 验证不再装死：被打断的验证自动重新派人接着干；验完证伪的直接标"不成立"，不再挂着"待确认"。
- 发现页改四栏：假设、事实、锤炼、成果，东西从左往右流动，出了结果的不再混在正在验的里面。
- 反证过程说人话：每轮按"疑点、怎么验的、结论"三段呈现，看不懂的机器原文折叠保留。
- 模型切换不再连环卡死：各家模型的思考内容按各家规矩传，主备切换、跨格式续跑都稳了。
- 全面提速：大账本任务各页面从卡顿到秒开，年轮图从两分半冻结提速到一秒内出图；界面文字按报告标准重写。

### v1.2.0（2026-11-07）

- 任务不再"假死"：修复两个会导致任务停摆的缺陷——模型接口无响应时现在 5 分钟自动断开并重试（此前会永远等待）；手里活全部完成但目标未达成时，系统继续规划下一步（此前会因"没有新事件"永久停摆）。
- 任务结束后状态如实收场：终止或完成的任务不再残留"排队中""验证中"等过期状态，工作台与虫群列表随之归零。
- 面板大幅提速：发现、虫群会话、任务列表改为按需加载，即点即开；此前一个大型任务能拖慢所有页面数十秒至数分钟。
- 数据库自动维护：写入暂存自动回收，不再无限膨胀拖慢读写；此前实测可涨至 855MB。
- 长任务成本下降：工具的大段输出自动存档（对话内保留索引，可按需读回），长对话不再随轮次线性膨胀。
- 后台命令设限：输出超 100MB 自动截断、超 30 分钟自动结束，杜绝单条命令刷出数十 GB 垃圾文件。
- 资产范围管理：给域名只测该域名，给 IP 测整台服务器；新建任务必选"渗透"或"红队"类型——渗透任务发现的新资产需批准后测试，红队任务直接测试；可随时摘除某个资产，相关在途步骤自动终止。
- 任务创建支持草稿：表单填一半可暂存，从任务列表随时继续；删除任务时可勾选"同时删除相关数据和账本"。
- 建任务新增"注意事项"：写明"用小字典、不要修改数据"等要求，虫群全程遵守，也可从描述一键提取。
- 换模型立即生效：切换主用模型后，所有在跑会话下一轮请求即走新模型。
- 成果/事实"深入"指令：任何一条发现（含已废弃的）可发起深入，可选填方向，系统立即规划执行。
- 未读提醒：成果和事实页有新确认内容时自动亮红点，看过即消。
- 复现步骤只保留必要步骤，每步说明动作与目的，请求包可直接复制到 Burp 发送。
- 冬眠任务释放并发名额，排队任务自动补位；任务并发上限可在系统设置中调整（默认 2）。
- 在途状态实时刷新（历史记录标注截至时间），已取消、已中止如实显示。
- 勾选操作即时响应，失败自动回弹；程序崩溃时堆栈写入运行日志。

### v1.1.0（2026-10-26）

- 派活有闸门：之前 AI 会不停领新活，干不过来就堆着，一个任务能积压几十条等几小时。现在同时在干加在排队的活有上限，干完一条补一条；已经过时的待办自动取消。任务跑得再久也不会越堆越多。
- 报告只有真漏洞：之前一些没实际危害的观察（比如验证码能自动过、端口一直开着）也被当成漏洞写进报告，看着热闹其实没用。现在这类内容只记为过程记录，报告里留下的条条都是需要处理的问题，级别也按统一标准校准。
- 模型断了不再丢进度：之前模型闪断三次，正在干活的单位就被放弃。现在改为原地等待、模型恢复后接着干；还修复了一个长对话导致请求损坏、单位被连环误杀的缺陷。任务状态一次只显示一种，不再同时挂两个状态让人误解。
- 界面整体换新：全新的深色与浅色两套主题，打开时自动跟随系统设置；面板底部显示版本号。
- 字体与排版统一：数字用等宽字体不再跳动，字号只分五级，间距统一取档，弹窗、抽屉与页面用同一套尺寸规则——整体观感不再杂乱。
- 发现页一眼看懂：每条发现分清是“还在验证中”还是“已有结论”，鼠标悬停有说明，状态词从 12 个精简到 6 个，未处理条目数量在页顶直接可见。
- 审批不再连环弹窗：同一件事批准一次后，后续命令不再逐条请求批准；每张待决卡新增危害说明——这条命令要做什么、目标会发生什么变化、最坏后果是什么。
- 诊断包按需导出：可以只导出某类日志（比如只看报错），也可以附加账本和会话记录用于深入排查；日志固定全量记录。

### v1.0.0（2026-10-16）

- 首次发布。
